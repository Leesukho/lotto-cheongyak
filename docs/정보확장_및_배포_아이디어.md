## 2. 반드시 바꿔야 할 구조: 중앙 수집 서버

지금은 PC마다 같은 공유 API 키로 15분마다 호출한다. 사용자가 늘면 일일 호출 한도(1,000~10,000건)를 바로 넘긴다.

```
[수집 서버 1대] ──15분마다──> 청약홈·마이홈·LH API, SH 게시판
      │ 새 공고만 DB에 저장 (공고 1건 = 시세·자격 계산 1번)
      ├─> 텔레그램 (단체방 / 개인 봇)
      ├─> 웹 푸시 (PWA)
      └─> 앱 푸시 (FCM, APK)
```

- 사용자 수와 관계없이 API 호출 수가 일정하다.
- 비용이 낮다: Cloudflare Workers/Cron, GitHub Actions cron, 저가 VPS 중 하나면 충분하다.
- PC 프로그램은 "서버를 쓰지 않는 개인용"으로 남기거나 서버의 클라이언트로 바꾼다.

## 3. 텔레그램: 채팅방을 여러 개 만들지 않는 방법

| 방식 | 장점 | 단점 | 추천 |
|---|---|---|---|
| A. 슈퍼그룹 + 토픽(주제) | 방 1개에 무순위 / APT 청약 / 행복주택 / LH / SH / 오늘 일정 탭. 사용자가 주제별로 알림을 끌 수 있음. 봇은 `message_thread_id`로 주제를 지정해 보냄 | 개인 조건(지역·자격) 필터는 안 됨 | 1단계 |
| B. 채널 + 해시태그 | 구독만 하면 됨. 인원 제한 없음. `#경기 #무순위`로 검색 가능 | 주제별 알림 끄기가 안 됨. 대화 불가 | A의 보조 |
| C. 개인 봇 DM + 구독 설정 | `/설정`으로 지역·유형·차익·자격을 고르면 맞는 것만 받음. 채팅방 1개 | 서버에 사용자 DB 필요 | 2단계 |
| D. 개인 봇 DM + 토픽 | C에 주제 탭까지 더함 | 최근 Bot API 기능이라 버그 보고가 있음 | 확인 후 검토 |

추천 조합: **A(공개 단체방, 전체 공고) + C(개인 맞춤, 내 조건에 맞는 것만)**.
단체방은 홍보와 유입 창구로 쓰고, 맞춤 알림은 개인 봇으로 보낸다. 그러면 "채팅창이 여러 개"인 문제가 생기지 않는다.

## 5. 메시지·화면 아이디어

- **일정형**: "이번 주 접수" 요약(월요일 아침), "내일 접수 시작" 전날 저녁 알림, "오늘 마감" 아침 알림.
- **분류 표시**: 🎯 로또(차익 큼) / 🏠 공공임대(행복주택 등) / 📋 일반 청약을 앞에 붙여 한눈에 구분.
- **행복주택용 요약**: 시세 차익 대신 보증금·월 임대료, 주변 시세 대비 비율, 대상(청년·신혼·고령자), 소득·자산 기준.
- **자격 설문 재사용**: 지금의 '내 조건'을 공공임대까지 넓힘(소득 구간, 자산, 나이, 혼인·자녀). 공고마다 ✅⚠️❌ 판정.
- **결과 콘텐츠**: 지난 공고의 경쟁률과 당첨 커트라인을 주간 요약으로 보냄. 단체방 참여를 늘리는 데 도움이 됨.

## 6. 단계별 로드맵

1. **지금(PC v1.x)**: 개인용 유지. 마이홈 API로 행복주택·LH 공고를 추가하고 PC에서 검증.
2. **1단계**: 수집 로직을 서버로 옮기고 텔레그램 토픽 단체방 1개를 운영.
3. **2단계**: 개인 봇 구독(지역·유형·자격)을 붙이고 사용자 DB 구축.
4. **3단계**: PWA(목록, 달력, 설문, 웹 푸시).
5. **4단계**: PWA를 감싼 APK(TWA) + FCM. 반응을 보고 네이티브 앱 여부 결정.
