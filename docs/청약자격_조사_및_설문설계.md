# 청약 자격 조사 및 앱 온보딩 설문 설계

- 기준일: 2026-10-31
- 목적: 무순위·계약취소주택 재공급 알림 앱에서 사용자별 "신청 가능성"을 사전 판정하기 위한 규칙 정리와 설문 설계
- 한계: 국가법령정보센터 현행 조문 페이지는 자동 수집이 되지 않았습니다. 그래서 개정문, 국토부 보도자료, **실제 입주자모집공고문 PDF**, 주요 언론으로 확인했습니다. `불확실` 표시 항목은 출시 전 법령 원문과 대조해야 합니다.
- 원칙: 앱 판정은 **참고용**입니다. 결과는 `가능 / 확인필요 / 불가` 3단계로 보여 주고, "최종 자격은 모집공고문·청약홈 기준"이라는 고지를 반드시 넣습니다.

## 1. 공고 유형별 핵심 자격

| 구분 | 무순위(사후접수) | 계약취소 재공급: 일반공급분 | 계약취소 재공급: 특별공급분 |
|---|---|---|---|
| 근거 | 규칙 제26조⑤ (2025-06-10 개정) | 규칙 제47조의3 | 제47조의3 + 원 특별공급 조항 |
| 신청자 | **성년 무주택세대구성원** | **무주택세대주** `불확실(2025년 이후 공고)` | 성년 무주택세대구성원 + **원 특공 유형 자격** |
| 거주 요건 | 지자체가 다음 중 선택: ① 해당 시·도 ② 광역권(수도권 = 서울·인천·경기) ③ 없음(전국). **시·군 단위 선택지는 없음** | **해당 주택건설지역(시·군 단위)** 거주 | 해당 주택건설지역 거주 |
| 거주기간 | 없음 | 없음 | 없음 |
| 청약통장 | 불필요 | 불필요 | 불필요 `추정` |
| 선정 | 추첨 | 추첨 | 추첨 |
| 무주택 판단일 | 해당 공고의 모집공고일 | 해당 공고의 모집공고일 | **최초** 모집공고일로 적은 공고가 있음 `불확실` |
| 재당첨제한 | 원 주택이 규제지역·분양가상한제 대상이면 적용(최대 10년), 비규제면 없음 | 같음 | 같음 + 특공 평생 1회 소진 |
| 당첨 후 | 당첨자로 전산관리. 5년간 규제지역 1순위 제한 여부는 `불확실` | 5년간 투기과열·조정지역 1순위 제한(공고 명시) | 같음 |
| 결격 | 외국인, 90일 초과 해외체류, 부적격 제한기간 중, 공급질서교란자 | 같음 + 재당첨제한 기간 중인 사람과 그 배우자 | 같음 + 특공 당첨이력 보유 |

- 무순위 실제 사례: 평택 고덕(2025-10)은 "전국", 올림픽파크 포레온 무순위 2차(2025-07)는 "서울특별시 거주"였습니다. **공고마다 다르므로 공고문 파싱이 필수**입니다.
- 당첨자 발표일이 같은 주택(APT, 재공급, 규제지역 무순위)은 1인 1건만 신청할 수 있습니다.

## 2. 무주택세대구성원

**세대 범위**
- 항상 포함: 본인, 배우자(분리세대여도 포함, 배우자 등본상 직계존비속까지 포함)
- 등본에 함께 있을 때만 포함: 직계존속(배우자의 직계존속 포함), 직계비속(그 배우자 포함)

**주택으로 보지 않는 예외 (제53조)**

| 예외 | 기준 | 일반 | 특공 |
|---|---|---|---|
| 소형·저가 아파트 1호 | 전용 60㎡ 이하, 공시가 수도권 1.6억·비수도권 1억 이하 | O | O (2023-11~) |
| 소형·저가 비아파트 1호 | 전용 85㎡ 이하, 공시가 수도권 5억·지방 3억 이하 | O | `불확실` |
| 60세 이상 직계존속 소유 주택 | 일반공급만 무주택 인정 | O | **X** (2024-03-25~) |
| 임차하던 비아파트 취득 | 2024년 취득한 생애 첫 주택, 60㎡ 이하, 2억(수도권 3억) 이하, 1년 이상 거주 | O | O |

- 분양권·입주권은 주택으로 봅니다. 단, 미분양 선착순으로 처음 취득한 경우는 제외합니다.
- 2주택 이상이면 예외를 적용하지 않습니다.

## 3. 특별공급 유형별 요건 (계약취소 특공분 판정용)

| 유형 | 핵심 요건 | 소득(민영) | 비고 |
|---|---|---|---|
| 신혼부부 | 혼인 7년 이내, 공고일 기준 세대 전원 무주택 | 우선 100%(맞벌이 120%), 일반 140%(160%), 초과 시 부동산 3.31억 이하이면 추첨 | 2025-03-31부터 본인·배우자의 혼인 전 당첨이력 배제 |
| 생애최초 | 세대 전원 **과거** 주택 소유 이력 없음, 소득세 5년 이상 납부, 혼인 중이거나 자녀 있음(1인가구는 일부 물량) | 우선 130%, 일반 160%, 초과 시 부동산 3.31억 | 출산 추가 1회 예외 **미적용** |
| 다자녀 | 미성년 자녀 **2명** 이상(태아·입양 포함) | 기준 없음 | 2024-03-25 완화 |
| 노부모부양 | 만 65세 이상 직계존속을 **3년 이상** 같은 등본으로 부양, **무주택세대주** | 기준 없음 | 1순위 필요 |
| 신생아 | 공고일 기준 **2세 미만** 자녀(태아 포함), 혼인 무관 | 우선 130%, 일반 160%, 추첨 `불확실` | **민영은 2026-06-15 신설** (특공의 10%) |
| 기관추천 | 국가유공자·장애인·중소기업 근로자 등 기관 추천 필요 | - | 앱에서는 "대상 여부"만 묻기 |

- 공공(국민주택) 기준은 다릅니다. 예: 신혼 130%/맞벌이 200%, 자산 부동산 2.155억·자동차 4,542만원(2026).
- % 기준은 **전년도 도시근로자 가구당 월평균소득**에 대한 비율이고 매년 3월경 갱신됩니다. **서버에서 연도별 기준표로 관리**해야 합니다.
- 특공은 세대당 평생 1회입니다. 예외: 2024-06-19 이후 출산 가구는 1회 추가(생애최초 제외).

## 4. 재당첨 제한·부적격·결격

| 항목 | 기준 |
|---|---|
| 재당첨제한 | 투기과열·분양가상한제 10년, 조정대상지역 7년, 기타 대상 주택은 과밀억제권역 5년/3년, 그 외 3년/1년(85㎡ 이하/초과). 본인과 세대원 전원에 적용 |
| 당첨자 관리 | 당첨되면 5년간 투기과열·조정지역 1순위 제한 |
| 부적격 당첨 | 수도권·규제지역 1년, 수도권 외 6개월, 위축지역 3개월 당첨 제한 |
| 해외체류 | 계속 90일 초과 시 거주자로 불인정(생업 목적 본인 체류는 예외) |
| 이력 확인 | 청약홈 → 청약자격확인 → 청약제한사항 확인(본인 인증). **앱이 직접 조회할 수 없으므로 사용자 입력과 딥링크로 처리** |

## 5. 규제지역 (투기과열지구 + 조정대상지역, 2026-10 기준)

- 서울 전역: 기존 4개 구에 2025-10-16 나머지 21개 구 추가
- 경기 12곳 (2025-10-16): 과천, 광명, 성남(분당·수정·중원), 수원(영통·장안·팔달), 안양 동안, 용인 수지, 의왕, 하남
- 경기 3곳 추가 (2026-07-01): 화성 동탄구, 용인 기흥구, 구리시
- 2026-08 이후 변동은 확인하지 못했습니다. **고정하지 말고 서버 DB로 갱신하고, 공고문의 규제지역 표기를 우선**합니다.

## 6. 일반공급 확장 대비 (참고)

- 1순위 요건
  - 비규제지역: 수도권 12개월, 비수도권 6개월 + 예치금
  - 규제지역: 24개월 + 세대주 + 5년 내 당첨 없음 + 2주택 이상 소유 세대 아님
- 민영 예치금 (85㎡ 이하 / 102㎡ / 135㎡ / 전체)
  - 서울·부산: 300 / 600 / 1,000 / 1,500만원
  - 기타 광역시: 250 / 400 / 700 / 1,000만원
  - 그 외: 200 / 300 / 400 / 500만원
- 가점(84점 만점)
  - 무주택기간: 최대 32점
  - 부양가족: 최대 35점
  - 통장 가입기간: 최대 17점. 2024-03부터 배우자 기간의 50%(최대 3점)를 합산합니다.
- 바로잡은 내용: "2026-06 수도권 1순위 강화"는 **사실이 아닙니다**. 그 개정의 핵심은 민영 신생아 특공 신설입니다.

## 7. 앱 온보딩 설문 설계

부담을 줄이기 위해 **3단계로 나눠 묻습니다**. 1단계만 답해도 알림과 기본 판정이 동작합니다.

### 1단계: 필수 (가입 시, 1분)
| 질문 | 형식 | 판정 용도 |
|---|---|---|
| 생년월일 | 날짜 | 성년 여부 |
| 주민등록 주소 | 시·도 → 시·군·구 선택 | 무순위 시·도/광역 요건, 재공급 시·군 요건 |
| 세대주인가요? | 예/아니오 | 재공급 일반분, 노부모 특공 |
| 세대 전원이 무주택인가요? | 예 / 아니오 / **잘 모르겠어요(도움말)** | 전 유형 |
| └ "아니오"일 때 | 보유 주택 유형·면적·공시가격·소재지 | 소형·저가 예외 자동 판정 |
| 90일 넘게 해외에 계속 체류 중인가요? | 예/아니오 | 결격 |
| 현재 재당첨제한·부적격 제한 기간인가요? | 예 / 아니오 / 모름(청약홈 확인 링크) | 결격 |

### 2단계: 특별공급 (선택, "특공 공고도 판정받기" 선택 시)
| 질문 | 판정 |
|---|---|
| 혼인신고일 (미혼·예비신혼·한부모 선택) | 신혼 7년, 생애최초 혼인 요건 |
| 자녀 생년월일 목록 (태아·입양 체크) | 신생아(2세 미만), 다자녀(미성년 2명), 출산 추가 1회 |
| 가구원 수, 전년도 세대 월평균소득, 맞벌이 여부 | 소득 % 구간 |
| 세대 부동산 공시가 합계, 자동차 가액 | 자산 기준 |
| 세대원 과거 주택 소유 이력 | 생애최초 |
| 소득세 납부 5년 이상 | 생애최초 |
| 만 65세 이상 직계존속 동일 등본 기간 | 노부모부양 |
| 과거 특별공급 당첨 이력(일자·유형·혼인 전 여부) | 평생 1회 |
| 기관추천 대상 여부 | 기관추천 |

### 3단계: 일반청약 확장 (향후)
- 청약통장: 가입일, 납입횟수, 예치금, 배우자 가입일
- 부양가족, 무주택 기간 → 가점 계산기

### 공고 쪽에 필요한 데이터 (서버 수집)
| 필드 | 출처 | 상태 |
|---|---|---|
| 유형(무순위/재공급), 지역, 일반·특별 세대수, 분양가, 면적 | 청약홈 API | 현재 구현됨 |
| 모집공고문 PDF | 청약홈 상세 페이지 | 현재 구현됨 |
| **무순위 거주요건(전국/광역/시·도)** | 공고문 PDF 파싱 | 미구현: **판정 정확도의 핵심** |
| **재당첨제한 기간, 규제지역·분양가상한제 여부** | 공고문 PDF 파싱 + 규제지역 DB | 미구현 |
| **재공급 특공분의 원 특공 유형** | 공고문 PDF 파싱 | 미구현 |

## 8. 배포 시 고려사항

- **개인정보 최소화**: 소득·자산·가족 정보는 민감합니다. 판정은 **기기 안(로컬)**에서 하고, 서버에는 알림 필터에 필요한 지역·유형만 보내는 구조를 권장합니다. 개인정보처리방침 부담도 크게 줄어듭니다.
- **기준값 외부화**: 소득 %, 자산 금액, 규제지역, 예치금은 매년 또는 수시로 바뀌므로 코드에 고정하지 않고 서버 기준표에서 내려받습니다.
- **면책 문구**: 판정 결과마다 "참고용, 최종 자격은 공고문 기준"을 표시합니다.
- **출시 전 검증 목록**: 위 `불확실` 항목을 법령 원문(제26조, 제47조의3, 제53조, 제54조, 별표)과 대조합니다.
